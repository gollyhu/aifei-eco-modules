功能说明

三个实例是什么

__MAIN__ 是主实例，配置走根级 mq.*；demoA / demoB 是命名实例，配置分别走 mq.demoA.* / mq.demoB.*，由 app-config.txt 的 mq.names 声明。

实例之间互不可见

每个实例是一条独立总线：消息记录、发送 / 接收计数、订阅登记都按实例分片。同名 topic 在 demoA 发出的消息，demoB 上收不到，主实例也收不到。

为什么页面上没有链路参数

本 demo 的消息后端是内存实现、同步投递：没有外部 broker，消息不跨进程边界，进程重启即清空。因此页面只表达「就绪 / 未装配」，也没有需要填写的链路参数。

端点用途

GET /mq/demo/messages?instance=该实例的消息记录（最新在前）
GET /mq/demo/subscribe?instance=&topic=为该实例订阅一个主题
GET /mq/demo/send?instance=&topic=&text=发送一条文本消息

全部 GET，HTTP 恒 200，业务结果看响应里的 code（0 为成功）。
