功能说明

本页连接的是哪个地址

本页在浏览器里直连 ws://127.0.0.1:18091/ws（demo 的 WS 服务端，端口 18091），与页面所在的 HTTP 18090 是不同端口；WebSocket 不受同源限制。仅支持 ws://，不支持 wss://。

echo 回声机制

demo 的 WS 服务端对每条收到的文本帧立刻原样回声回同一会话，所以本页「发什么就能收到什么」，用于自测收发闭环；收到的内容与发出的内容一致即表示链路正常。

主动 close 不重连

点「断开」= 本页主动 close()，永不触发自动重连（日志明确记「主动关闭 —— 不会自动重连」）；只有服务端踢掉 / 网络异常等非主动断开才会进入自动重连（勾选复选框时）。

发送不排队

非 OPEN 状态下发送会直接失败并丢弃消息，不会缓存、不会在重连后补发；因此非 OPEN 时「发送」按钮被禁用并给出提示。

demo 侧与本页侧状态的区别

信息栏左段是本页浏览器连接的状态与计数；右段是demo 进程内部那对客户端/服务端的状态（每 2s 从 /ws/demo/state 拉取）。两者是两条独立连接，本页的连接变化不会改变 demo 侧指标，反之亦然。

本页日志 vs demo 事件日志

右下日志是本页的；demo 侧事件日志最新在前、上限 200 条，需要时用下面的端点手动查看。

demo 端点速查（9 个）

以下地址均指 demo 进程内部的客户端/服务端，不是本页浏览器的连接，在浏览器地址栏手动访问即可（全部 GET，HTTP 恒 200，code=0 为成功）：

端点用途
/ws/demo/state现场快照（本页右段指标就来自它）
/ws/demo/log只取 demo 事件日志（最新在前，上限 200）
/ws/demo/log/clear清空 demo 事件日志
/ws/demo/echo/send?text=hello经 demo 客户端发送，服务端回声
/ws/demo/broadcast?text=notice服务端向全部会话广播
/ws/demo/server/stop停掉 demo WS 服务端（demo 客户端随即断线并自动重连）
/ws/demo/server/start重启 demo WS 服务端（demo 客户端自动回到 OPEN）
/ws/demo/client/connect手动建连（仅 demo 客户端 CLOSED 时可用）
/ws/demo/client/disconnect手动关闭 demo 客户端（之后不再自动重连）

说明：这 9 个端点的操作入口不进入页面五区（功能范围已锁定），仅在此以文字速查形式给出。
